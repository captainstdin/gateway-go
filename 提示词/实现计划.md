# GatewayWorker-Go 实现计划

## 架构总览

三服务 + 独立客户端 SDK 架构，内部通讯全部使用 **AES 加密**。

```
Client(TCP/WebSocket) ──► Gateway ◄──GatewayProtocol+AES──► BusinessWorker
                              │  ▲                               │
                              │  └──GatewayProtocol+AES── GatewayClient(独立SDK)
                              └───text/json+AES───► Register ◄───┘
```

- **Register**：注册中心，维护 Gateway/Worker 地址列表
- **Gateway**：网关，对外同时支持 **TCP** 和 **WebSocket**，对内通过 GatewayProtocol 与 Worker 通讯
- **BusinessWorker**：业务处理器，接收 Gateway 转发的事件，调用用户回调
- **GatewayClient**：独立 SDK，可从任意进程直连 Gateway 下发消息/踢人/查询等，无需经过 Worker

## 1. AES 加密层 (`pkg/crypto/aes.go`)

所有内部通讯（Register⇔Gateway、Register⇔Worker、Gateway⇔Worker）在传输前加密，接收后解密。

```go
package crypto

// AES-256-CBC，密钥由 SecretKey 派生（SHA256取32字节）
// 加密后格式: [16字节IV] + [密文]

func DeriveKey(secretKey string) []byte      // SHA256(secretKey) → 32字节
func Encrypt(plaintext, key []byte) []byte   // AES-256-CBC 加密
func Decrypt(ciphertext, key []byte) []byte  // AES-256-CBC 解密
```

**集成方式**：
- Register 的 text 协议：JSON 序列化后 → AES 加密 → Base64 编码 → `\n` 分隔发送
- GatewayProtocol：整个二进制包（含头部）→ AES 加密 → 前置4字节密文长度 → 发送

## 2. GatewayProtocol (`pkg/protocol/gateway_protocol.go`)

Gateway 与 Worker 间的二进制协议，头部28字节，Big-Endian，与 PHP 版格式一致。

### 包头结构

| 字段 | 类型 | 字节 | 说明 |
|------|------|------|------|
| pack_len | uint32 | 4 | 整包长度 |
| cmd | uint8 | 1 | 命令字 |
| local_ip | uint32 | 4 | Gateway内网IP |
| local_port | uint16 | 2 | Gateway内部端口 |
| client_ip | uint32 | 4 | 客户端IP |
| client_port | uint16 | 2 | 客户端端口 |
| connection_id | uint32 | 4 | 连接ID |
| flag | uint8 | 1 | 标志位 |
| gateway_port | uint16 | 2 | Gateway监听端口 |
| ext_len | uint32 | 4 | ext_data长度 |
| ext_data | []byte | 变长 | session等扩展数据 |
| body | []byte | 变长 | 包体 |

### 命令字

```go
const (
    CmdOnConnect    = 1    // Gateway→Worker: 新连接
    CmdOnMessage    = 3    // Gateway→Worker: 客户端消息
    CmdOnClose      = 4    // Gateway→Worker: 连接关闭
    CmdSendToOne    = 5    // Worker→Gateway: 发给单个客户端
    CmdSendToAll    = 6    // Worker→Gateway: 广播
    CmdKick         = 7    // Worker→Gateway: 踢出客户端
    CmdDestroy      = 8    // Worker→Gateway: 销毁连接
    CmdUpdateSession = 9   // Worker→Gateway: 合并session
    CmdGetAllClientSessions = 10
    CmdIsOnline     = 11
    CmdBindUID      = 12
    CmdUnbindUID    = 13
    CmdSendToUID    = 14
    CmdGetClientIDByUID = 15
    CmdBatchGetClientIDByUID = 16
    CmdJoinGroup    = 20
    CmdLeaveGroup   = 21
    CmdSendToGroup  = 22
    CmdGetClientSessionsByGroup = 23
    CmdGetClientCountByGroup = 24
    CmdSelect       = 25
    CmdGetGroupIDList = 26
    CmdUngroup      = 27
    CmdBatchGetClientCountByGroup = 28
    CmdWorkerConnect = 200
    CmdPing         = 201
    CmdGatewayClientConnect = 202

```

## 4. Register 服务 (`pkg/register/register.go`)

TCP 监听，文本协议（JSON + AES + `\n` 分隔）。

### 核心逻辑

```go
type Register struct {
    ListenAddr  string
    SecretKey   string
    aesKey      []byte              // DeriveKey(SecretKey)
    gateways    map[int]string      // connID → gateway内部地址
    workers     map[int]net.Conn    // connID → worker连接
    mu          sync.RWMutex
}
```

**事件处理**：

| 事件 | 来源 | 处理 |
|------|------|------|
| `gateway_connect` | Gateway | 验证密钥，存储地址，广播给所有Worker |
| `worker_connect` | Worker | 验证密钥，存储连接，回复当前Gateway地址列表 |
| `ping` | 任意 | 忽略（保活） |
| 连接关闭 | Gateway | 移除地址，重新广播 |
| 连接关闭 | Worker | 移除连接 |

- 新连接10秒内未认证则断开
- 广播消息格式：`{"event":"broadcast_addresses","addresses":["ip:port",...]}`

## 5. Gateway 服务 (`pkg/gateway/`)

### 5.1 客户端连接抽象 (`client_conn.go`)

统一 TCP 和 WebSocket 的读写接口：

```go
// ClientConn 统一接口
type ClientConn interface {
    Read() ([]byte, error)
    Write(data []byte) error
    Close() error

}

// WebSocketClientConn 实现
type WebSocketClientConn struct { conn *websocket.Conn }

// TCPClientConn 实现（需要定义应用层协议，建议：4字节长度头+body）
type TCPClientConn struct { conn net.Conn }
```

### 5.2 Gateway 核心 (`gateway.go`)

```go
type Gateway struct {
    // 对外监听配置
    WebSocketAddr   string  // 如 ":7272"
    TCPAddr         string  // 如 ":7273"（可选，为空则不启TCP）

    // 内部通讯配置
    LanIP           string  // 内网IP，默认 "127.0.0.1"
    LanPort         int     // 自动分配 startPort+id
    StartPort       int     // 默认 54321
    RegisterAddr    []string
    SecretKey       string
    aesKey          []byte

    // 心跳
    PingInterval         int
    PingNotResponseLimit int
    PingData             string

    // 路由模式
    LoadBalancingMode string // "random" | "least_connections"

    // 连接管理（全部加读写锁）
    clientConns     map[uint32]*ClientConnection
    uidConns        map[string]map[uint32]*ClientConnection
    groupConns      map[string]map[uint32]*ClientConnection
    workerConns     map[string]net.Conn     // workerKey → conn
    leastConnRecord map[string]int
    connIDCounter   uint32
    mu              sync.RWMutex
}

type ClientConnection struct {
    ID                 uint32
    Conn               ClientConn          // TCP 或 WebSocket
    ConnType           string              // "tcp" | "websocket"
    Session            string
    UID                string
    Groups             map[string]bool
    GatewayHeader      *protocol.GatewayData
    PingNotRespCount   int
    BoundWorkerAddr    string              // 路由绑定的worker地址
}
```

### 5.3 Gateway 启动流程

1. 分配 `lanPort = startPort + id`
2. 启动 WebSocket 监听（gorilla/websocket）
3. 启动 TCP 监听（可选）
4. 启动内部 TCP 监听（`lanIP:lanPort`，GatewayProtocol+AES），用于接受 Worker 连接
5. 向 Register 注册自身地址
6. 启动心跳定时器

### 5.4 关键方法

**客户端相关**：

| 方法 | 说明 |
|------|------|
| `onClientConnect(conn)` | 生成connID，初始化header，保存连接，转发`CMD_ON_CONNECT`给Worker |
| `onClientMessage(conn, data)` | 重置心跳计数，转发`CMD_ON_MESSAGE` |
| `onClientClose(conn)` | 转发`CMD_ON_CLOSE`，清理uid/group映射，更新路由表 |
| `onWebsocketConnect(conn, req)` | 提取HTTP头/GET参数/Cookie，转发`CMD_ON_WEBSOCKET_CONNECT` |
| `sendToWorker(cmd, conn, body)` | 路由选择worker，AES加密后用GatewayProtocol发送 |

**Worker指令处理 (`onWorkerMessage`)**：处理30+种CMD，包括：
- 连接管理：`SEND_TO_ONE`, `KICK`, `DESTROY`
- 广播：`SEND_TO_ALL`, `SEND_TO_GROUP`, `SEND_TO_UID`
- UID操作：`BIND_UID`, `UNBIND_UID`, `GET_CLIENT_ID_BY_UID`
- Group操作：`JOIN_GROUP`, `LEAVE_GROUP`, `UNGROUP`
- Session：`SET_SESSION`, `UPDATE_SESSION`, `GET_SESSION_BY_CLIENT_ID`
- 查询：`IS_ONLINE`, `SELECT`, `GET_ALL_CLIENT_SESSIONS`, `GET_CLIENT_COUNT_BY_GROUP`

## 6. BusinessWorker 服务 (`pkg/worker/business_worker.go`)

```go
type BusinessWorker struct {
    RegisterAddr  []string
    SecretKey     string
    Name          string
    ID            int
    aesKey        []byte

    // 用户业务回调
    OnWorkerStart      func()
    OnWorkerStop       func()
    OnConnect          func(clientID string)
    OnMessage          func(clientID string, message []byte)
    OnClose            func(clientID string)
    OnWebSocketConnect func(clientID string, data []byte)

    // 内部状态
    gatewayConns     map[string]net.Conn  // addr → gateway连接
    gatewayAddrs     map[string]string    // Register广播的地址列表
    connectingAddrs  map[string]bool
    waitingAddrs     map[string]bool
    mu               sync.RWMutex
}
```

### 核心流程

1. **启动** → 连接Register（AES加密通讯），发送`worker_connect`
2. **收到`broadcast_addresses`** → 更新gateway地址列表，连接新Gateway
3. **连接Gateway** → GatewayProtocol+AES发送`CMD_WORKER_CONNECT`（含worker_key+secret_key）
4. **收到Gateway转发数据** → 解密 → 解码 → 设置Context → 调用回调
5. **断线重连** → Gateway断开自动重连，Register断开自动重连

### 收到Gateway数据的处理

```go
func (bw *BusinessWorker) onGatewayMessage(conn net.Conn, data *GatewayData) {
    // 设置 Context
    ctx := &context.Context{
        LocalIP:      data.LocalIP,
        LocalPort:    data.LocalPort,
        ClientIP:     data.ClientIP,
        ClientPort:   data.ClientPort,
        ConnectionID: data.ConnectionID,
        ClientID:     context.AddressToClientID(data.LocalIP, data.LocalPort, data.ConnectionID),
        Session:      context.SessionDecode(data.ExtData),
    }
    // 保存到 goroutine-local 或传参
    switch data.Cmd {
    case CmdOnConnect:    bw.OnConnect(ctx.ClientID)
    case CmdOnMessage:    bw.OnMessage(ctx.ClientID, data.Body)
    case CmdOnClose:      bw.OnClose(ctx.ClientID)
    case CmdOnWebSocketConnect: bw.OnWebSocketConnect(ctx.ClientID, data.Body)
    case CmdPing:         // 忽略
    }
}
```

## 8. 内部通讯加密流程

### Register ⇔ Gateway/Worker（文本协议 + AES）

```
发送方: JSON字符串 → AES-256-CBC加密 → Base64编码 → 追加\n → 发送
接收方: 按\n分隔 → Base64解码 → AES-256-CBC解密 → JSON解析
```

### Gateway ⇔ Worker（GatewayProtocol + AES）

```
发送方: GatewayProtocol.Encode() → AES加密 → 前置4字节(密文长度,BigEndian) → 发送
接收方: 读4字节长度 → 读密文 → AES解密 → GatewayProtocol.Decode()
```

### 密钥派生

```
AES Key = SHA256(SecretKey)  → 32字节 → AES-256
```

## 9. GatewayClient 独立 SDK (`pkg/gateway_client/gateway_client.go`)

独立于 BusinessWorker 的客户端 SDK，可从任意 Go 进程（如 HTTP API 服务器、定时任务、管理后台等）直接连接 Gateway 内部端口，执行推送消息、踢人、查询在线状态等操作。

对应 PHP 版 `Lib/Gateway.php` 在非 Workerman 环境下的工作模式。

### 核心结构

```go
type GatewayClient struct {
    RegisterAddr  []string         // 注册中心地址
    SecretKey     string
    aesKey        []byte
    ConnTimeout   time.Duration    // 连接超时，默认3秒

    // 连接池：address → conn（带TTL自动过期重建）
    connPool      map[string]*poolEntry
    mu            sync.RWMutex

    // Gateway地址缓存（从Register获取，1秒过期）
    addrCache     []string
    addrCacheTime time.Time
}

type poolEntry struct {
    conn        net.Conn
    createdAt   time.Time
}
```

### 工作原理

1. **发现 Gateway**：连接 Register，发送 `worker_connect` 获取所有 Gateway 内部地址列表（带缓存，1秒过期）
2. **连接 Gateway**：通过连接池复用 TCP 连接，首次连接时发送 `CMD_GATEWAY_CLIENT_CONNECT`（携带 secret_key）进行认证
3. **发送指令**：使用 GatewayProtocol 编码 + AES 加密，发送到对应 Gateway
4. **接收响应**：查询类命令（isOnline、getSession 等）需要同步等待 Gateway 回复

### 寻址方式

- **指定 client_id 的操作**：从 client_id 中解码出 `localIP:localPort`，直接发给对应 Gateway
- **广播类操作**：发给所有 Gateway
- **UID/Group 操作**：发给所有 Gateway（每个 Gateway 自行判断是否有对应连接）

### 使用示例

```go
package main

import "gatewayworker-go/pkg/gateway_client"

func main() {
    // 创建 GatewayClient
    client := gateway_client.New(
        []string{"127.0.0.1:51234"},
        "my-secret-key",
    )
    defer client.Close()

    // 从 HTTP 接口中推送消息给指定用户
    client.SendToUID("user-123", []byte(`{"type":"notification","msg":"hello"}`))

    // 广播给所有在线客户端
    client.SendToAll([]byte(`{"type":"announcement","msg":"server will restart"}`), nil, nil)

    // 查询在线数
    count, _ := client.GetAllClientCount()
    fmt.Println("online:", count)
}
```

### 连接池管理

- 每个 Gateway 地址维护一个 TCP 长连接，TTL 50秒后自动重建
- 连接断开或 EOF 时自动移除，下次请求重新创建
- `Close()` 方法关闭所有连接

### 与 gateway_api 的区别

| | gateway_api | gateway_client |
|---|---|---|
| 使用场景 | Worker 回调内部 | 任意外部进程 |
| 连接方式 | 复用 Worker 已有的 Gateway 连接 | 自行建立到 Gateway 的连接 |
| Gateway 发现 | 通过 Worker 内部地址表 | 连接 Register 查询 |
| 认证命令 | `CMD_WORKER_CONNECT` | `CMD_GATEWAY_CLIENT_CONNECT` |
| 并发安全 | 依赖 Worker 单 goroutine | 自带连接池 + sync.RWMutex |

## 10. TCP 客户端协议

Gateway 对外 TCP 服务使用简单的长度前缀协议：

```
| 4字节 pack_len (BigEndian) | pack_len字节 body |
```

- 客户端发送：`[4字节长度][消息体]`
- Gateway 发送给客户端：同格式

WebSocket 客户端直接使用 WebSocket 帧，无需额外封装。
